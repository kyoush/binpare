# Diff & Match Display Specification (Draft)

目的
- 2つのバイナリの差分/一致領域を視認性よく表示し、ユーザが任意領域を蛍光ペン的にハイライトできるようにする。大きなファイルでも対話的に動くことを重視する。

全体方針（設計決定）
- デフォルトの差分粒度は「行単位」を維持しつつ、ユーザ操作で任意の範囲（バイトオフセット範囲）を選択して枠＋蛍光カラーで強調できる機能を提供する。
- 差分（違い）を赤で強調する従来の表示はオプション化し、デフォルトは「差分行の自動強調は表示しない」。代わりに「一致領域（match）」の視認を優先する（ユーザは差分ハイライトをONにできる）。
- 一致領域は常に表示（デフォルト）し、折り畳みはデフォルトOFF。折り畳みは設定で有効化可能（閾値: 連続一致行数 >= N、デフォルト N=64）。
- 同期スクロールはデフォルト ON。

表示モード（UI）
- Split view (左右並列)：左=File A、右=File B（デフォルト）。
- ユーザ操作で以下を切り替え可能：
  - 差分ハイライト (Off / Row / Byte)
  - 任意範囲選択モード（マウスドラッグまたは Shift+クリック で開始/終了）
  - 一致領域折り畳みトグル（閾値設定）
  - 同期スクロールトグル

任意範囲ハイライト（蛍光ペン的表示）
- 操作: ユーザがペイン内でドラッグ（あるいは Shift+クリック で範囲指定）すると、そのバイト範囲が矩形の背景色（蛍光色）で強調される。
- 表示実装: Painter を使い、行内の該当バイト列位置に矩形を描画して背景を色付けし、その上に既存のテキスト（hex/ASCII）を重ねて表示する。これによりウィジェット数を増やさず高速に描画できる。
- 範囲情報はアプリ内で保持でき、複数のハイライト（色ごとにラベル付け）を許可する。ハイライトは保存/読み込み可能とする（将来）。

差分ハイライト（優先実装項目）
- ユーザが差分ハイライトを ON にすると: キャッシュ済み diff ベクタを利用して、差分バイト（または差分行）をハイライト表示する。
- 行単位モード: 行内に1つの背景矩形（既に実装している行単位強調）を Painter で描画するか、ラベル色で目立たせる。
- バイト単位モード: バイト単位で背景矩形を描画（Painter）し、テキストは一度にレンダリングする（per-row label）ことで性能を確保する。

一致領域の扱い
- デフォルト: 一致領域はそのまま表示する（ユーザは折り畳みを有効にできる）。
- 折り畳み時の表現: "... N lines omitted" のクリックで展開。展開は部分的に行う（ユーザが前後数行分のコンテキストを指定可能）。

ナビゲーションとショートカット
- n: 次の差分（差分ハイライト ON のとき）
- p: 前の差分
- g: オフセットへジャンプ（ダイアログで 0x... を入力）
- f: 差分検索（バイト列を16進で検索）

パフォーマンス要件
- 10MB 程度のファイルはスムーズにスクロールできること（目安: 60 FPS を目指すが環境依存）。
- diff 計算は一度だけ行いキャッシュする（既に実装済み）。
- 描画はウィジェット数を増やさない戦略（行ごとに 1~2 ラベル + Painter による背景描画）を採る。

受け入れ基準
1. 任意範囲をドラッグして蛍光矩形でハイライトできること（Painter 描画）。
2. 差分ハイライト ON 時に、n/p で差分へジャンプできること。
3. 同期スクロール ON のとき左右ペインの縦位置が揃うこと。

優先実装（次のタスク）
1. 差分ハイライト（行/バイト選択式） — 優先度高（ユーザ指定）
2. 任意範囲選択と蛍光ペン描画（Painter）
3. 折り畳みオプション（閾値設定）

次の確認事項（ユーザへ）
1. 差分行の自動強調はデフォルト OFF、代わりに一致視認を重視する仕様で OK か？
2. 任意範囲ハイライトで色や透過度の希望があれば指定してください（デフォルト: 蛍光イエロー、alpha 0.35）。
3. 優先実装を差分ハイライト（あなたの選択）で進めます。実装方針は上記で問題ないですか？
