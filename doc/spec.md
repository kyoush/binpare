# binpare

Binpare — A fast, minimal GUI tool to compare binary files. Implemented in Rust using eframe/egui.

## 概要

バイナリファイルを視覚的に比較し、差分を直感的に把握できる軽量なデスクトップツールです。

## 現在の機能

### ファイル読み込み

- メニューからファイル選択（File > Load File A/B）
- 非同期読み込みで UI がブロックされない
- 大容量ファイル対応（10MB 制限）
- エラーハンドリング付き

### バイナリ表示

- hexdump 形式の 16 進データ表示
- 隣接する ASCII 文字表示
- 設定可能な 1 行あたりのバイト数（8-32）
- 仮想スクロール対応（パフォーマンス最適化）

### ファイル比較

- A/B 2 ファイルの並列表示
- バイト単位での差分検出
- リアルタイム差分ハイライト（赤背景+白文字）
- オフセット処理対応

### UI/UX

- ファイル名の明確な表示
- 差分ハイライトの ON/OFF 切り替え
- レスポンシブなインターフェース
- 10FPS 制限で CPU 使用量最適化

### 技術仕様

- Rust + eframe/egui
- マルチスレッド非同期処理
- スレッドセーフなデータ管理
- メモリ効率的な仮想スクロール

## アーキテクチャ

### 主要コンポーネント

1. **BinpareApp**: メインアプリケーション構造体
2. **FileState**: ファイルの状態管理
3. **DiffState**: 差分計算・表示状態
4. **UIState**: UI 設定とインタラクション
5. **LoadedFile**: スレッドセーフなファイルデータ管理

### データフロー

```
[File Dialog] → [Async Load] → [FileState] → [Diff Calc] → [UI Render]
```

### パフォーマンス最適化

- 表示行数制限（1000 行）
- フレームレート制限（10FPS）
- 大ファイル用チャンク処理
- 効率的な差分計算アルゴリズム

## 使用方法

1. アプリケーション起動
2. File > Load File A でファイル A 選択
3. File > Load File B でファイル B 選択
4. View > Highlight Differences で差分表示切り替え
5. Bytes per row スライダーで表示調整

## 技術的特徴

### エラーハンドリング

- カスタムエラー型（BinpareError）
- 適切なエラー伝播
- ユーザーフレンドリーなエラー表示

### コード品質

- Clippy 準拠

- 包括的なドキュメンテーション
